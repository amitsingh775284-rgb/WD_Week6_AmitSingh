## 📌 Project Overview
This is a fully responsive and interactive web application developed as part of the 6-week Web Development Internship. The project utilizes HTML5 for structure, CSS3 (Flexbox & Grid) for styling and responsive design, and JavaScript for dynamic interactivity.

## 🚀 Technologies Used
- **HTML5** - Semantic layout structure
- **CSS3** - Flexbox, Grid, Media Queries, CSS Variables
- **JavaScript (ES6+)** - DOM Manipulation, Event Handling, Dynamic Filtering
- **Git & GitHub** - Version Control & GitHub Pages Hosting

## 🛠️ Features
- **Responsive Layout:** Works smoothly across Mobile, Tablet, and Desktop screens.
- **Dynamic Content:** Interactive elements powered by JavaScript.
- **Form Handling:** Interactive form validation and event listeners.
